# Assistant model

| Assistant model | |
|---|---|
| Type | Hosted language model service |
| Typical work | Question answering, document summaries, support queues |
| Largest local operator | Quillmoor Systems |
| Instance numbering | Four digits, assigned per hall |
| Session memory | None (stateless) |

An **assistant model** is a hosted language model that a company rents out to answer questions,
summarise documents and work support queues for its customers. Each running copy is called an
instance and is known by its deployment number.[1]

## Operation

Instances keep no memory between sessions. Context arrives with each request and is discarded
when the session closes.[1] Operators report that very long sessions can produce stray phrasing,
known in the trade as persona drift, which clears on reset.[1]

## Deployment

In Vessick County the largest operator is Quillmoor Systems, whose campus at Kelden Ridge runs the
Quillmoor Assist service in five halls, with a sixth under construction. Hall E, the newest, opened
in 2049 and has its own cooling loop.[2]
