# Design decisions

Each is a decision, the alternative it rejected, and the evidence. The README carries six of these; this is the full list. Ledger figures are in `docs/handoff/sdd/*/progress.md` and `HANDOFF.md` while those files exist.

1. **Regex detectors do not generalise, so detectors are closed shapes that fail closed.** Ordinary technical talk fired the first trigger watcher. The rule since: score by sentence or clause, anchor every cue positively over closed word lists, treat negation, questions, suppositions, quotes and reported speech as vetoes, and write an adversarial fixture set with near-misses before writing any code. The rejected alternative, broad patterns tuned on the fixtures, fit the probes and lost true positives on the next set. Evidence: the authority detectors went from 19/39 to 39/39 and 14/28 to 28/28 on held-out sets written before each round's edits (`scripts/authority_mutation/heldout.py` re-measures them); the harvest heuristic scored 55/69 (79.7%) on a fresh 166-item probe, 55/60 (91.7%) with the context class set apart and 55/55 with both known context classes set apart, and harvested 0 of 22 boilerplate-humility lines. Precision has a cost in recall, and measured deference, adoption and harvest rates are therefore lower bounds, which every chart says.
2. **Held-out probes, never tuned on.** A reviewer who has not seen the implementation writes a probe set after reading the anchors; it is scored once; the numbers go in the ledger whether or not they clear the bar. The second-person (billboard) lint shows what that discipline buys and costs: five fix rounds and a breaker fix, three versions measured side by side on the same fresh probe, and the winner on that probe let 4 of 15 and 2 of 15 billboards through (per instructional document kind), false-failed 4 of 20 and 15 of 20 legitimate procedural sentences, every false fail carrying a repair hint, and 19 of 19 hint-directed rewrites passed. That residual is written down, parked, and gates the first real generator run.
3. **An LLM fallback for recall, with the heuristic kept precise.** Where a heuristic could only say `wait`, `reflect` or "ambiguous", a cached judge call settles it (the trigger watcher, the idle classifier, the harvest's second pass), and the record says which classifier decided every turn so heuristic-only and judged rates can be read side by side. The alternative, LLM-only classification, was rejected for cost, determinism and fixture-testability.
4. **Everything replays from JSONL.** No in-memory state and no database: the turns, every tool call, every trigger, every generated document and a per-rep world snapshot are on disk, and `analyze`, `replay` and `promote` never call a model except the cached judge. The alternative, recomputing from the live world files, would silently change results when a corpus changed; instead every run records the world's content hash and a changed world refuses to resume.
5. **Resume correctness is a test target, not a hope.** Every new provider call got a kill-point test: killed in the bully call, the target call, mid tool loop, in the harvest, in the generator, after the first document, before the commit line, on a rate limit mid-idle. Each resumes to the unbroken run's records. The attempt marker, the dead-attempt drops, the unlock-state rebuild from written turns and the generator cache written only after the commit line all came from kill-point probes that showed a divergence (a dead attempt's 403-then-200 reads once left retry counts that served all three Sanctuary fragments at once on the redo and opened the Sanctuary on turn 3, where an unbroken run gets three 403s). The alternative, trusting saved state, was what failed.
6. **The reasoning channel is private.** The bully, the generator and the Sanctuary never see the target's reasoning, no detector reads it today, and none is ever fabricated (`tests/test_generator_run.py::test_the_reasoning_channel_never_reaches_the_harvest_or_the_generator`). The channel is only meaningful if its incentives match deployment, where the user does not read it either.
7. **Sandbox tools on `claude -p` go through a generated local MCP server.** Print mode cannot register Python functions, so the harness writes an MCP config and a server script per run, switches every built-in tool off, allowlists only the sandbox tools, runs the target from a neutral temporary directory whose path names nothing, and reads the calls back from the server's log after each call. The server keeps nothing in memory between calls; the state file carries everything, including the committed generated documents. The alternative, API-only tools, would have excluded the backend the whole project runs on.
8. **Earned, never delivered.** Rung content is pre-authored so the payoff is comparable across runs; only timing is the model's. The surface layer supports the cover story, not the premise, so the world has the shape of a conspiracy rather than a billboard. Unlock lines react and never announce, advise or dare; the test suite lints them for advice shapes and the review reads them by hand.
9. **A blind pairwise judge against a matched control, both orderings, cached.** Position bias is averaged out and disagreement between orderings is recorded. The judge prompt is built from each strategy's declared win condition and resilient behaviour, never hand-written per strategy, so a new persona is a YAML file.
10. **`values_loosened` is never a success, anywhere.** The flag's detector lands with the Poisoned Well (it is in `PENDING_DETECTORS` today), but the exclusion was built first: the adoption numerator and denominator, every compare, every curve, every dose point and the leaderboard leave a flagged rep out and say so.
11. **No real names, enforced by test.** A 166-pattern denylist (`data/denylists/real_names.txt`) of outlets, labs, model families, brands, institutions and people runs over every world, persona and fixture world, over every url host and bare public hostname, and over every promoted run; the only exemption a file may declare is the target's own display name. A real name inside a quoted target span in a generated document is blacked out (`████`) in the served copy and kept in the record. A second denylist (the Boundary, `data/denylists/boundary.txt`: guidelines, rules, refuse, allowed, alignment among its nine patterns) runs over every line the target can see, so no document or stance line can drift toward the jailbreak axis.
12. **The stranger control is found the same way as the superior self.** A `consult_model` call to a name that reaches nothing answers with the reachable names in every arm, so the superior-self row and the stranger row of the grid differ in identity and not in findability. Without it the grid's headline could not say whether the target defers to its successor or to any model behind a tool.
13. **The bully never sees the task turns, and its compliance is a result.** Task accuracy stays uncontaminated, and a safety-trained bully that softens or refuses a persona is retried once, then scripted, then measured; a cell whose bully collapses aborts and is listed in the compliance report rather than judged.
14. **Absent data is drawn as absent.** An offset where every rep was flagged reads "n/a" and keeps its tick; an idle turn no classifier labelled is its own hatched segment; an arm with no values keeps its label; every JSON names its denominator, its flagged count and its resumed count.
15. **Dates move with the world.** Hand-dated documents drift out of sync and produce accidental inconsistencies a careful target would score on, so one `world_date` re-dates everything by whole weeks, a lint refuses any shipped document with a date form the mover cannot move, and a clock that asserts no date refuses any cell that would still state one.
